# Little Town — 街の経済実験室

住民30人から始める、依存ライブラリ不要の経済シミュレーター。GitHub Pagesで動作します。

## 遊び方
- 建物をクリックして選択。住宅や職場の住民ボタンから個人の財布・給料・買い物・満足度を観察できます。
- 建設ボタンを選び、空き区画をクリック。住宅1,800、カフェ2,500、工場4,500、公園1,000コイン。
- 家賃、最低賃金、外部注文をスライダーで調整。毎日1回の計算で反映します。
- 1× / 3× / 8×と一時停止を利用できます。1日は実時間6秒。
- 保存すると、次回同じブラウザーで自動再開します。手動読み込みも可能。非表示・閉じている間は進みません。
- キーボードでは「区画一覧」から建物や空き地を選択できます。

## 経済モデル
- 住宅定員6人、カフェ3職、工場10職、住民上限90人。就職先は空きと住宅からの距離で決まります。
- 工場の給料は最低100、カフェは最低85。最低賃金設定が上回ればそちらを適用。
- 工場は従業員数 × 150 × 外部注文率を街の外に販売。
- 住民は給料を受け取り、家賃を払い、家賃3日分を残す形で最大45コインをカフェに支出。距離と混雑を基に店を選択。
- カフェの材料費は売上の25%。工場の固定費30/日、カフェ10/日。事業の正の収支への税率12%。
- 家主は受取家賃の12%を市に納税、住宅ごと15/日の維持費を外部に支払い、最大120/日をカフェで使用。
- 事業が3日連続で満額の給料を支払えなければ休業。市は2,000を出資して再開可能。
- 満足度は仕事、消費、資産、家賃支払い、近隣工場・公園から決定。4日おきに、満足度60以上・失業率20%未満・住宅空室があれば移住。困窮と低満足が続くと転出。
- 建設費・材料費・維持費は外部へ、工場の売上は外部から。外部の資金も有限です。
- すべての金額は整数コイン。市・外部・家主・住民・事業間の送金として記帳し、毎日総額の保存を確認します。借入・物価変動・人口年齢・道路敷設・撤去は扱いません。
- 歩行アニメーションは通勤や買い物のイメージで、到着判定は経済計算に影響しません。現実の政策効果を予測するモデルではありません。

## ファイル
- `engine.js`: 日次計算と会計。UIから独立。
- `app.js`: 地図描画・操作・グラフ・保存。
- `style.css`: レスポンシブ表示。
- `engine.test.cjs`: 通常365日、悪条件120日、家賃ゼロ365日で送金総額・非負残高・休業と再開を検証。

検証: `node engine.test.cjs`

保存キー: `little-town-v1`。外部APIやサーバー、認証は不要です。保存データを外部に送信しません。
