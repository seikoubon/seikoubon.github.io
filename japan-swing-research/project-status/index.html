売買のアイデアを、数字で確かめる

たとえば「増配を発表した企業の株価は、その後も上がりやすいか」。価格や出来高、決算、配当などのデータを使い、こうした問いを誰が実行しても同じ結果になる売買ルールにします。

  1. 仮説を立てる

    AIが値動きの理由を考え、どの銘柄をいつ買い、いつ手放すかを先に決めます。

  2. 過去を再現する

    その時点で知ることができた情報で取引を再現し、市場全体の目安となるTOPIXや、条件の近い銘柄と比べます。

  3. 別の時期と市場で確かめる

    同じルールを別の時期でも試します。残った候補は紙上取引で、日々のデータから注文を組めるかを確認します。

保有日数の例　月曜の取引開始時に買うと、寄り引けは同じ月曜の終了時に売ります。5営業日のスイングでは、休場がなければ金曜の終了時まで保有します。

11月24日の追加判断

増配ルールとの組み合わせは見送り

既存のスイングペア（A08＋SW-020）に、増配で予想配当利回りが3%未満から3%以上になった銘柄を10営業日保有するルール（IDR26）を組み合わせました。仮想の500万円を半分ずつ割り当て、IDR26用の半分を現金のままにした場合と比べました。

2024〜2025年は組み合わせた方が利益を増やしました。2026年の追試では差がマイナスに転じ、費用を見込むと差はさらに開きました。この結果を受け、組み合わせの紙上取引への追加を見送りました。IDR26単独は別の枠で紙上検証を続けています。

2026年は11月24日までに確認できた開示と価格を使った過去データの再現です。新規探索でも、費用と現金との比較を含めて両期間で改善した案はありませんでした。

11月20日の報告から、何が進んだか

  1. 11月20日

    同じ銘柄でも、保有日数で結果が変わった

    寄り引けの2,492案を5日と10日で試しました。既存判定で見送られた44案のうち、2022年・2023年の両方で黒字かつTOPIXを上回った買い単独ルールが12案ありました。追加検証の候補を絞るための結果です。

  2. 11月23日

    古い相場と、後の相場でも試した

    既存スイング5案を2017〜2021年の利用可能な範囲で再検証し、IDR26の10日版だけを紙上検証に進めました。台帳から選んだ寄り引け3案も2024年以降に再検証し、追加は0案でした。

  3. 11月24日

    戦略の組み合わせと、利益の出どころを調べた

    基本ルール98仕様から4,753ペアを比較しました。主要な口座では、市場の上げ下げや業種、値動きの大きさを考慮して利益とリスクを点検。増配ルールを既存ペアに加える案は、2026年の追試を受けて見送りました。

  4. 11月25日

    登録済みの組み合わせを紙上で観察

    A09＋H04、A08＋SW-020、D04＋SW-015、BS07＋D05の4ペアを紙上取引に登録。11月25日朝の準備記録は完了しています。前日までのデータから候補を選び、現金や保有枠を管理して、モデル上の約定を記録します。

次に確かめること

注文が組めるか

新しい取引日で、開示が締め切り前に届いたか、100株単位で注文できるか、当日の市場でどの程度の数量を取引できるかを確認します。

利益が一部の日に偏っていないか

費用を引き、利益の大きい数日を外しても効果が残るかを調べます。市場全体の上昇や、特定の業種・値動きの大きい株への偏りも点検します。

財務データが揃うか

売上総利益を総資産で割る新仮説は、使える初回の有価証券報告書が不足しているため保留中です。訂正前の原本と公表日時を揃えてから検証します。

用語と資料

バックテストと紙上取引

バックテストは過去の相場に売買ルールを当てはめるシミュレーションです。紙上取引では、その日に得られた市場データを使い、仮想資金で注文・約定を記録します。どちらの金額も実資金での取引成績とは区別します。

TOPIXとの比較

TOPIXは日本の株式市場の動きを見る指数です。この研究では、各取引と同じ金額・同じ保有期間をTOPIXに当てはめた損益を目安にし、銘柄を選んだ効果を見ます。今回の比較は配当を含まない価格ベースです。

取引費用と最大ドローダウン

往復費用は買いから売りまでにかかる費用の仮定です。最大ドローダウンは、口座残高が直前までの最高値から最も大きく下がった割合です。利益と一緒に、途中でどれだけ資産が減ったかを確認します。
