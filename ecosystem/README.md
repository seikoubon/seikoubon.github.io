# mori — 小さな生態系

Canvas 2Dで描く、草・ウサギ・キツネの島。外部ライブラリ・通信・ビルド不要。

## 遊び方
1. 1× / 3× / 8×で時間を調整。
2. 動物をクリックして個体を観察。
3. 草や動物を追加し、草の育ちやすさを調整。
4. 「島を保存」でブラウザー内に保存。次回自動復元。

## モデル
固定50ms刻み。空腹、食事、繁殖、寿命を計算する簡略モデル。個体数の保証はなく、絶滅も起こります。1日約8秒。草最大600株、動物合計240匹。自然繁殖のキツネ上限20匹（手動追加可能）。非表示中は進行を停止。履歴120日。

## 実装
index.html: UI / style.css: responsive styling / app.js: simulation and rendering.
