# 四季報 スクリーニング表エクスポート

Brave / Chrome の個人用拡張機能。ログイン済みの会社四季報オンラインのスクリーニング結果を、**CSVダウンロード**または**タブ区切りでクリップボードにコピー**できます。

## 導入
1. このフォルダの4ファイルをダウンロードし、同じフォルダに保存する（またはGitHubのCode > Download ZIPでリポジトリ全体をダウンロードする）。
2. Braveで `brave://extensions/` を開く。
3. デベロッパーモードを有効にし「パッケージ化されていない拡張機能を読み込む」でこのフォルダを指定する。
4. 四季報オンラインでスクリーニング結果を開き、拡張機能のボタンから出力方式を選択する。

## 仕様
- 表示中の銘柄と列見出しを取得（非表示・未表示のデータは取得しません）。
- CSVはUTF-8 BOM付き、クリップボードはExcel/Google Sheets向けTSV。
- 画面に表示される件数と取得件数が一致しない場合は処理を中止。
- ログイン自動化、外部APIへのアクセス、データ送信は行いません。
- 画面構造が変わった場合は修正が必要なことがあります。
- サービスの利用条件に従って利用してください。

このフォルダはソースコード公開用です。公開トップページからのリンクは設けていません。
